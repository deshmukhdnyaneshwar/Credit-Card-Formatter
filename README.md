# 💳 Credit Card Formatter

A simple and interactive **Credit Card Formatter** built using HTML, CSS, and JavaScript.

This project formats credit card numbers as the user enters them, making the input easier to read and providing a clean and user-friendly form interface.

## 🚀 Features

* 💳 Format credit card numbers automatically
* ⌨️ Format input while typing
* 🔢 Add spaces between card number groups
* 🚫 Restrict unnecessary characters
* 🔢 Limit the number of digits
* ⚡ Real-time input formatting
* 📱 Responsive design
* 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

* CSS3
* JavaScript

## ⚙️ How It Works

The Credit Card Formatter uses JavaScript to process the user's input and automatically format the card number.

### Formatting Process

1. User enters a credit card number.
2. JavaScript captures the input value.
3. Non-numeric characters are removed.
4. The card number is grouped into sections.
5. Spaces are added between the groups.
6. The formatted number is displayed in real time.

### Example

Without formatting:

```text
1234567812345678
```

After formatting:

```text
1234 5678 1234 5678
```
